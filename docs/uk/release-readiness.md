# Чекліст релізу

[English](../en/release-readiness.md) · **Українська**

Пройдіть цей список перед публікацією версії. Тут описано, що перевірити, а не
що перевірено для якоїсь минулої збірки — результати записуйте в нотатки до
релізу.

## Автоматичні перевірки

Запустіть `tools/Package-Release.ps1`. Він збирає мод (і встановлює його
локально для тестів), запускає тести профілів, перевіряє, що кожен параметр
CFG і його значення за замовчуванням описані обома мовами, що обидва README
показують правильну кількість параметрів і бейдж версії, звіряє номери
версій, посилання й ліцензію та створює ZIP із файлом SHA-256 у `artifacts/`.

Тримайте `README.md` / `README.uk.md` і `docs/en` / `docs/uk` синхронними:
кожна зміна функцій чи параметрів іде в обидві мови.

Запишіть версії .NET SDK, BepInEx і Valheim, з якими зібрано реліз.

## У грі

- [ ] Чистий профіль BepInEx лише з цією DLL: без помилок завантаження й
      Harmony, CFG створюється, мод працює без інших модів Hero і редактора.
- [ ] Колесо консумаблів з 0, 1–2 і багатьма предметами; скасування в центрі;
      застосування відпусканням; кілька предметів кліком; золота/червона
      реакція на клік; стак, що закінчується під час відкриття.
- [ ] ConsumeAnimation true/false; відмови через кулдаун зілля й ситість.
- [ ] Вікно статів на обох колесах: положення, розмір, текст, оновлення ваги.
- [ ] Колесо стріл: коротке натискання й утримання R, додаткова клавіша,
      перепризначення, несумісні боєприпаси, повернення схованого лука.
- [ ] Курсор гри видно в обох колесах і він повертається після закриття;
      прицілювання збігається з курсором при зміщеннях і масштабі.
- [ ] Захист від інвентаря/чату/мапи/меню, смерть, телепорт, вихід і повернення
      у світ; керування відновлюється після примусового закриття.
- [ ] Зміни CFG діють без перезапуску; зміщення — після перезаходу у світ.
- [ ] Параметри вигляду, BlockMovement, 1080p/1440p і масштаб інтерфейсу.
- [ ] Профілі редактора: зміна й видалення при відкритому й закритому колесі,
      колеса незалежні одне від одного.
- [ ] Клієнт у мультиплеєрі з вимкненим SlowMotion; SlowMotion в одиночній грі.
- [ ] Ручне встановлення, оновлення поверх попередньої версії, видалення;
      менеджер модів, якщо його заявлено.

Обмеження, які треба вказати на сторінці релізу: прицілювання лише мишею, до
16 предметів на колесо, частина тексту в грі українською. SlowMotion працює
лише на клієнті й не перевірявся з іншими модами часу. Сховані профілем слоти
все одно можна вибрати.

## Матеріали для публікації

- [ ] Превʼю `docs/images/preview.png` (показується вгорі обох README),
      скриншоти або коротке відео релізної збірки.
- [ ] Публічна адреса вихідного коду/підтримки та представлення автора.
- [ ] Коміт і тег для релізної версії.
- [ ] Для Thunderstore: manifest.json, icon.png 256×256 і README.md у корені
      ZIP (поточний ZIP розрахований на ручне встановлення / Nexus).
