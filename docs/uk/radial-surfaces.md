# Формат профілів редактора для коліс

[English](../en/radial-surfaces.md) · **Українська**

Профіль — необов'язковий JSON-файл, який тонко налаштовує одне колесо поверх
CFG: положення й масштаб, кольори, видимість і розмір окремих частин. Зазвичай
профілі створюють у **Valheim UI Editor** — окремому візуальному редакторі
інтерфейсу цих модів від автора; він не входить у мод і для гри не потрібен.
Ця сторінка описує формат файлу, тож профіль можна написати або перевірити й
вручну.

ID плагіна: com.heromod.valheim.radialmenus.
Кожне колесо має власний профіль у BepInEx/config/HeroModUiProfiles:

- com.heromod.valheim.radialmenus.heal-wheel.json
- com.heromod.valheim.radialmenus.arrow-wheel.json

Для звичайної гри ні редактор, ні профіль не потрібні. Якщо колесо виглядає
не так, винесіть його профіль з папки, щоб виключити профіль як причину.

## Поверхні та ID вузлів

Використовуйте повний префікс **heal-wheel** або **arrow-wheel**, а не heal чи
arrow. Обидва колеса мають однаковий набір вузлів.

| Суфікс після ID поверхні | Об'єкт | Властивості профілю, що діють |
|---|---|---|
| .root | HeroQuickHealRadial / HeroArrowRadial | pos, scale; видимістю керує відкриття/закриття меню |
| .dim | Dim | tint, alpha, enabled |
| .wheel | ProceduralGraphic | enabled; геометрія береться з CFG |
| .highlighter | Highlighter | tint, alpha, enabled |
| .cursor | Cursor | enabled |
| .cursor.tip | CursorTip | pos, tint, alpha, size |
| .centerLabel | CenterLabel | text.size, text.color, tint, enabled; text.value належить грі |
| .slot[i] | ProceduralSlot_i | enabled; положення та вміст належать грі |

`.cursor` і `.cursor.tip` — це маленька стрілка-вказівник усередині колеса,
а не курсор миші.

Інші властивості RectTransform теж приймаються, але підтримуваний формат —
саме ця таблиця. Колесо малює сектори само, тож size/alpha для `.wheel` не
змінюють їх надійно: використовуйте Radius і кольори в CFG або scale для
`.root`. Вимкнений `slot[i]` ховає лише іконку, а не сектор і не вибір; це не
фільтр предметів.

Вікно статів предмета ліворуч від колеса не є вузлом профілю. Його положення
й розмір задаються параметрами CFG ShowItemInfo, ItemInfoScale і
ItemInfoOffsetX/Y.

## Приклад

Збережіть як com.heromod.valheim.radialmenus.heal-wheel.json:

```json
{
  "schemaVersion": 1,
  "overrides": {
    "heal-wheel.root": { "pos": [40, -25], "scale": [0.9, 0.9] },
    "heal-wheel.dim": { "alpha": 0.2 },
    "heal-wheel.cursor.tip": { "size": [95, 20], "tint": [1, 0.72, 0.36, 1] },
    "heal-wheel.centerLabel": { "text": { "size": 20 } }
  }
}
```

Використовуйте schemaVersion 1. Новіші схеми й зіпсований JSON ігноруються з
попередженням у лозі. Якщо прибрати override (або весь файл), властивість
повертається до базового значення; розмір `cursor.tip` — до 95 × 20. Його
`pos` задається відносно стрілки, що обертається: [0, distance] — відстань від
центру; без override стрілка стоїть на 10 одиниць всередині від секторів.

## Коли застосовуються зміни

Порядок: базова розкладка → CFG → профіль. Кожне колесо перевіряє свій файл
профілю під час оновлення HUD. Зміни при закритому колесі застосовуються
одразу, при відкритому — наступного разу, коли воно відкриється. CFG теж
перечитується після збереження, і наступне відкриття бере нові значення.

Рухомі частини (орнамент, стрілка-вказівник і слоти) колесо анімує щокадру.
Профіль може їх сховати, перефарбувати чи зробити прозорішими, але не
закріпити положення: видимість — це видимість від гри І від профілю, а
прозорість — alpha кольору × анімація × alpha профілю.

Radius використовується напряму, а нижче 200 замінюється на 320. Внутрішній
край = Radius − 86; зовнішній = Radius + 94; центри іконок = Radius + 4.
Секторів від 3 до 16, перший — вгорі, далі за годинниковою стрілкою. SlotSize
задає розмір іконок. Див. [усі параметри CFG](configuration.md).
